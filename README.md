Comic Book Store:
A full-stack web application developed as a collaborative capstone project to simulate an online comic book store. The application was designed to provide users with an interactive experience for browsing and managing comic book inventory while demonstrating modern web development practices, team collaboration, and Git workflows.

About the Project:
This project was built as part of the Coding Dojo Full-Stack Software Development program. The goal was to apply software development concepts in a team environment while gaining experience with full-stack architecture, collaborative development, source control, and project delivery.

Features:
Browse comic book inventory
View detailed comic information
Responsive user interface
Database-driven application design
Frontend and backend integration
CRUD functionality for managing application data
Server-side validation and data persistence

Installation:
Prerequisites:
Java JDK 17+ (or project-required version)
Maven
MySQL
Clone the Repository:
git clone https://github.com/BertoAguilar/ComicBookStore.git
Navigate to the Project Directory
cd ComicBookStore
Build the Project
mvn clean install
Run the Application
mvn spring-boot:run
Access the Application
Open your browser and navigate to:

http://localhost:8080
